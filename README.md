## 🎯 Задача
Абитуриенты сталкиваются с переизбытком разрозненной информации при поступлении. Наша задача — создать ИИ-сервис с сильным UX/UI, который превращает профиль пользователя в понятный пошаговый маршрут: куда поступать, почему этот вариант подходит и что делать прямо сейчас.

## 💡 Решение
Мы разработали веб-приложение, которое проводит пользователя через связный сценарий:
1. **Интерактивная анкета (Профиль):** Сбор данных о классе, бюджете, интересах и желаемых странах (с поддержкой ролей "Абитуриент" и "Родитель").
2. **Диагностика и Рекомендации:** Генерация подходящих программ бакалавриата с понятным объяснением выбора на основе данных пользователя.
3. **Сравнение:** Возможность отложить вузы и сравнить их ключевые параметры.
4. **Персональный Roadmap:** Пошаговый план поступления с выделенным главным действием ("Фокус на этой неделе") и возможностью отмечать прогресс.

## 🛠 Стек и архитектура
*   **Frontend:** React, Tailwind CSS, Vite. Отвечает за отзывчивый интерфейс, единую дизайн-систему и управление состояниями (переходы между экранами без перезагрузки).
*   **Backend:** Python, FastAPI. Обрабатывает запросы с фронтенда, формирует системные промпты и взаимодействует с LLM.
*   **AI / API:** OpenAI API (gpt-3.5/gpt-4) для генерации персонализированных рекомендаций и маршрутов.

## 🚀 Инструкция по локальному запуску

**1. Клонирование репозитория:**
`git clone [ссылка на ваш репозиторий]`

**2. Запуск Backend (FastAPI):**
`cd backend`
`python3 -m venv venv`
`source venv/bin/activate` (для Windows: `venv\Scripts\activate`)
`pip install -r requirements.txt` (или `pip install fastapi uvicorn pydantic openai python-dotenv`)
*Важно: Создайте файл `.env` в папке backend и добавьте ваш ключ: `OPENAI_API_KEY=ваш_ключ`*
`uvicorn main:app --reload` (Сервер запустится на http://127.0.0.1:8000)

**3. Запуск Frontend (React):**
Откройте новый терминал.
`cd frontend`
`npm install`
`npm run dev` (Приложение будет доступно на http://localhost:5173)

## 🧪 Тестовый сценарий для жюри
1. Откройте главную страницу сервиса.
2. В блоке анкеты выберите роль (например, "Я абитуриент").
3. Укажите курс (например, "2 курс колледжа"), выберите интересы (Data Science, UX Design), страну (Италия) и бюджет.
4. Нажмите "Построить маршрут".
5. На экране результатов изучите карточку диагностики и предложенные университеты (обратите внимание на объяснение "Почему подходит").
6. Выберите 2-3 вуза для сравнения и проверьте таблицу.
7. В карточке университета нажмите кнопку для построения Roadmap и изучите персональный план с выделенным первым шагом.

## ⚠️ Ограничения и готовые компоненты
*   В проекте использована базовая инфраструктура Vite для быстрого старта React-приложения.
*   Интерфейс сгенерирован и стилизован с использованием AI-инструментов (Antigravity/Cursor) в процессе хакатона.
*   Демонстрационная версия не сохраняет сессии пользователей в базу данных (используется локальное состояние React). Требования и дедлайны университетов генерируются ИИ и требуют финальной верификации на официальных сайтах вузов.
